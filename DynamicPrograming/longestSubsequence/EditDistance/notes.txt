Edit Distance
Edit Distance = minimum number of operations needed to convert s1 into s2.
There are 3 operations:
Insert a character
Delete a character
Replace a character

Example
s1 = "cat"
s2 = "cut"
Change:
cat
 ↓
cut
Replace a with u.

Edit Distance = 1

s2 = "ros"

The easiest way is: look at what the DP is asking. That's the whole difference.
1)      why 
LCS("", "a")  = 0
LCS("", "ab") = 0
Therefore: dp = [0, 0, 0, ...]

but in edit dist is 
"" → ""     = 0 operations
"" → "a"    = 1 insertion
"" → "ab"   = 2 insertions
Therefore: dp = [0, 1, 2, ...]

1. LCS asks: "How much can I KEEP?"
s1 = ""
s2 = "abc"
There is nothing in s1 to match with "abc".
so LCS("", "abc") = 0
Therefore:
dp = [0, 0, 0, 0]
It doesn't matter that "abc" has 3 characters, because we are counting common characters, not operations.
2. Edit Distance asks: "How many operations do I NEED?"
s1 = ""
s2 = "abc"
To convert: "" → "abc"
we need:

"" → "a"   = 1 insertion
"a" → "ab" = 1 insertion
"ab" → "abc" = 1 insertion

Total: 3 operations
