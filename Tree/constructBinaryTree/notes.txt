can we construct unique binary from given same preorder and inorder
ans:- yes we can 

✅ Inorder + Preorder → Unique Tree
✅ Inorder + Postorder → Unique Tree
❌ Preorder + Postorder → Not Unique

traversal:- 
      1
     / \
    2   3

1) preorder(Root → Left → Right)  1 2 3
2) inorder(Left → Root → Right) 2 1 3
3) postorder(Left → Right → Root) 2 3 1

Case 1: Inorder + Preorder ✅ (Unique)

Suppose
Preorder = [1,2,4,5,3]
Inorder  = [4,2,5,1,3]

Step 1
Preorder says:- Root = 1
Tree starts as
      1

Step 2
Find 1 in inorder.  4 2 5 |1| 3
Immediately you know
Left subtree : 4 2 5
Right subtree: 3

Draw it
          1
        /   \
     ???     ???
Now you know exactly which nodes belong to each side.

Step 3
Use preorder again.
Remaining preorder:- 2 4 5 | 3

The next root is :- 2
Because inorder already told us that 2 belongs to the left subtree.

Continue recursively.
Only one tree can be built.
Why is Inorder special?

Because inorder tells us
Which nodes are on the LEFT.  Which nodes are on the RIGHT
Without that split, we are guessing.

notes:- You're thinking:
Postorder = Left → Right → Root, so the first element must be the left child.
That's not true.
The first element of postorder is NOT necessarily the left child. It is simply the first node visited during the traversal.
