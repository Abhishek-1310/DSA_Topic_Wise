Largest BST
You're given a binary tree. Your task is to find the size of the largest subtree within this binary tree that also satisfies
 the properties of a Binary Search Tree (BST). The size of a subtree is defined as the number of nodes it contains.

Note: A subtree of the binary tree is considered a BST if for every node in that subtree, the left child is less than the node,
 and the right child is greater than the node, without any duplicate values in the subtree.

Examples :

       / \
      2   4
     / \
    1   3
Input: root = [5, 2, 4, 1, 3]

Output: 3

Case 1: Empty subtree (null)

We return

new NodeValue(Infinity, -Infinity, 0)

Why?

Suppose we have

    10
   /
 null

We want the condition

left.max < root.data < right.min

to work.

For the left subtree:

left.max = -Infinity

So

-Infinity < 10

✅ Always true.

For the right subtree:

right.min = Infinity

So

10 < Infinity

✅ Always true.

That's why for an empty subtree:

min = +Infinity
max = -Infinity

      10

    X   ← not a BST

We do not want the parent to think this subtree is valid.

So we intentionally return

new NodeValue(-Infinity, Infinity, size)

Now the parent checks

left.max < root.data

becomes

Infinity < 10

❌ False.

Even if that somehow passed, the other condition is

10 < -Infinity

❌ False.

So the parent can never combine an invalid subtree into a BST.
