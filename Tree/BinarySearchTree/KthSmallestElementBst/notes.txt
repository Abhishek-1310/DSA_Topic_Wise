230. Kth Smallest Element in a BST
Given the root of a binary search tree, and an integer k, return the kth smallest value (1-indexed) of all the values of the 
nodes in the tree.

Example 1:
        3
       / \
      1   4
       \
        2
Input: root = [3,1,4,null,2], k = 1
Output: 1
