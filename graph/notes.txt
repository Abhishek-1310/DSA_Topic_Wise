3 way to repersent graph in js

    0
   / \
  1---2
  |
  3

1. Edge List (Simplest)
Store every edge as a pair.
const edges = [
    [0, 1],
    [0, 2],
    [1, 2],
    [1, 3]
];

2. Adjacency Matrix

Suppose there are 4 vertices (0–3).

Create a 4 × 4 matrix.
If an edge exists,
matrix[u][v] = 1  otherwise = 0
For our graph,

      0 1 2 3
    ----------
0 |   0 1 1 0
1 |   1 0 1 1
2 |   1 1 0 0
3 |   0 1 0 0

3. Adjacency List ⭐ (Most Important)
This is the representation used in almost every graph algorithm.
Instead of storing every possible edge, each node stores its neighbors.
For our graph,

0 -> 1 -> 2
1 -> 0 -> 2 -> 3
2 -> 0 -> 1
3 -> 1




2) code Adjacency matrix 
const n = 4;

const matrix = Array.from({ length: n }, () => Array(n).fill(0));
const edges = [
    [0, 1],
    [0, 2],
    [1, 2],
    [1, 3]
];
for (const [u, v] of edges) {
    matrix[u][v] = 1;
    matrix[v][u] = 1; // Undirected graph
}

console.log(matrix);

3) const n = 4;

const adj = Array.from({ length: n }, () => []);

const edges = [
    [0, 1],
    [0, 2],
    [1, 2],
    [1, 3]
];
for (const [u, v] of edges) {
    adj[u].push(v);
    adj[v].push(u); // Undirected graph
}

console.log(adj);


Which representation is used in interviews?
Representation	           Space	Edge Check	    Used in Interviews
Edge List	                O(E)        O(E)	    Input format
Adjacency Matrix	        O(V²)	    O(1)	     Rare
Adjacency List	           O(V + E)	    O(degree)	⭐ Almost always
